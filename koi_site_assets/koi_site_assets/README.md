# Koi Japanese-style website assets

## Main pieces

1. `hero-banner-koi-cherry.png` is the full-resolution hero art.
2. `hero-banner-koi-cherry-1600.webp` is the recommended website version.
3. `icons/` contains the six stat card SVG icons.
4. `sidebar-bottom-panel-art.svg` is the dark sidebar art panel.
5. `decor/` contains optional decorative SVGs for the paper pattern, cherry corners, and brush dividers.
6. `style-tokens.css` contains starter colors and reusable classes.

## Suggested layout mapping

- Top hero: use `hero-banner-koi-cherry-1600.webp` as a background image on the main content header.
- Stat cards: use the SVGs inside `icons/` at 44 to 56 px.
- Sidebar bottom: place `sidebar-bottom-panel-art.svg` as an image near the bottom of the sidebar.
- Page background: use `decor/seigaiha-pattern.svg` as a subtle repeat background over an off-white base.
- Section headers: use `decor/ink-brush-divider.svg` under headings.
